check the following characteristics in every collection datatype

1.whether it follows dynamic memory allocation or not
2. different datatypes are supported or not supported
3. duplicate values are supported or not supported
4. sorting is supported by default
5. mutable or immutable
6. ordered collection or unordered collection
7. support index or not
